# Eu te amo

Uma declaração de amor em formato de slideshow, criada com nossas lembranças.

## Ver o site

https://anderhonorato.github.io/eu-te-amo-/

O projeto é responsivo e começa com a animação “Eu te amo”, seguida por um vídeo vertical em tela cheia. Depois, apresenta 47 lembranças entre fotos e vídeos, transições suaves, navegação por setas, indicadores e gesto de arrastar no celular.
